# كيدي توب — YouTube للصغار

تطبيق ويب بسيط بحال YouTube Kids: فيديوهات مختارة، أزرار كبار، وبدون تعليقات أو شات.

## كيفاش تفتحو

1. حلّ الملف `index.html` فـ Chrome أو Edge.
2. اختار عمر الطفل.
3. رقم الأهل الافتراضي: `0000`.

ما كاينش Node على الجهاز، لذلك المشروع HTML / CSS / JS فقط.

## الحماية

- بلا تعليقات وبلا رسائل
- كتالوج ثابت (ما كاينش بحث مفتوح على الإنترنت)
- فلتر حسب العمر
- مؤقت يومي + قفل للوالدين
- ترجمة CC (عربية / فرنسية) من زر المشغّل أو إعدادات الأهل

الفيديوهات الحالية تجريبية (ملفات عامة للعرض، Big Buck Bunny برخصة CC BY). تقدر تبدّلها من `js/data.js`.
ملفات الترجمة: `captions/*.vtt`.
